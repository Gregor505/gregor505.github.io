YouTube Playlist Organizer

A personal desktop application developed as part of the Library of Alexandria project.

What does it do?

YouTube Playlist Organizer is a Windows application that helps its owner organize videos into YouTube playlists, manage large video libraries, and track upload progress.

The application can organize videos by duration, manage playlist jobs, and resume interrupted operations.

Google Account Access

The application uses Google's authorization system to access the YouTube account explicitly authorized by its owner.

It uses YouTube API services to read playlist data and perform owner-approved playlist operations.

Personal Use

This application is currently intended for personal use and is not offered as a public service.

It is an independent project and is not affiliated with or endorsed by Google or YouTube.
